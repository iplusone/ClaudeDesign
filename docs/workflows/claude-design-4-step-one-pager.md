# Claude Design 4ステップ・ワークフロー

Claude Design を `Vibe Designing` ではなく、戦略的な実行ツールとして使うための1ページ要約です。

## 概要

無計画なプロンプト入力によるトークン浪費を防ぐには、デザイン前の準備を仕組み化することが重要です。

このワークフローでは、以下の4ステップで初回出力の精度を高めます。

1. デザインシステムを構築する
2. 再利用可能なテンプレートを作る
3. AIスキルでコピーを事前定義する
4. Claude Code へシームレスに移行する

## ステップ1: デザインシステムの構築

ブランドの色、フォント、ボタン形状を事前に定義し、一貫性を保ちます。

- ブランドカラー
- タイポグラフィ
- ボタンスタイル
- スペーシング

## ステップ2: 再利用可能なテンプレート作成

構造、つまり `スケルトン` を先に決めることで、レイアウト微調整の手間を減らします。

- LP
- 提案書
- ケーススタディ
- スライド

こうした定番構成をテンプレート化しておくと、毎回ゼロから組み立てずに済みます。

## ステップ3: AIスキルによるコピーの事前定義

文章作成は Claude Design の外で行い、デザイン用トークンの消費を最小限に抑えます。

- Claude Code / Claude Desktop の Skill を使う
- ブランドトーンを維持する
- セクションごとのコピーを先に確定する

## ステップ4: Claude Code へのシームレスな移行

完成したデザインは Claude Code に渡し、実装可能なアプリや画面へつなげます。

- UIから実装へ移行する
- フロントエンド構造を引き継ぐ
- 必要に応じて機能実装へ進める

## 仕組み化のメリット

システムとテンプレートを連携させることで、無駄なリテイクを減らせます。

- 初回出力の完成度が上がる
- ブランドの一貫性が保ちやすい
- 制作時間を短縮できる
- トークン消費を抑えられる

## 従来のやり方との比較

| 比較項目 | 従来のやり方 | 4ステップ・ワークフロー |
| --- | --- | --- |
| 制作時間 | 数時間から数日 | 10分以内を目指しやすい |
| ブランドの一貫性 | プロンプトごとにばらつく | デザインシステムで安定する |
| トークン消費 | 修正のたびに増える | 実行中心で最小化しやすい |

## メッセージ
