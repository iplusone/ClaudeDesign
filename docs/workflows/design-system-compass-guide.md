# AIデザインの羅針盤

Claude Design を使うときに `バイブ・デザイン` から脱却し、デザインシステムを起点に一貫した成果物を作るためのガイドです。

## 1. はじめに

Claude Design を開いて、次のように依頼するケースは多くあります。

```text
AIエージェンシーのランディングページを作って
```

これは `バイブ・デザイン` の典型です。問題は、AIに一度に多くの意思決定を任せすぎることにあります。

- 色
- フォント
- レイアウト
- コピー
- 構造

この状態では、AIが大量の推測を行うため、ブランドの一貫性が崩れやすく、Claude Design 専用の限られた利用枠も消耗しやすくなります。

プロの現場では、AIを魔法の箱として扱わず、厳密な `実行エンジン` として扱います。

## 2. バイブ・デザイン vs システム・デザイン

感覚的に指示を出す方法と、設計図を用意して進める方法では、品質と効率に大きな差が出ます。

| 比較項目 | バイブ・デザイン | システム・デザイン |
| --- | --- | --- |
| 決定の主体 | AIの推測 | 人間のルール |
| 一貫性 | 低い | 高い |
| リソース効率 | 悪い | 良い |
| 再現性 | 低い | 高い |
| 修正コスト | 高い | 低い |

### なぜ事前ルールが必要か

1. AIの推測を減らせる
2. レイアウト再生成によるトークン浪費を防げる
3. 人間が判断に集中できる

## 3. デザインシステムとは何か

デザインシステムは、ブランドの `設計図` です。Claude Design の右側にある `Design Systems` タブから定義します。

### 定義すべき4要素

- `Colors`: ブランドカラーとHEXコード
- `Typography`: フォントの選択と役割
- `Button Styles`: ボタンの形状や角丸
- `Spacing`: 要素間の余白ルール

これらを固定することで、AIは毎回違うスタイルを選ばず、常にブランドに沿った出力を出しやすくなります。

## 4. 一貫性を生む4ステップ

### 1. デザインシステムの構築

- 内容: `Design Systems` タブでルールを定義する
- 理由: スタイル判断をAIに委ねないため

### 2. テンプレートの作成

- 内容: `Examples` などからレイアウトを選び、骨格を作る
- 理由: レイアウト調整は最もコストが高いから

### 3. コピーの定義

- 内容: Claude Design の外で、Claude Desktop や Claude Code の `Skills` を使って文章を先に確定させる
- 理由: Claude Design は執筆環境ではないから

### 4. 実行と微調整

- 内容: 定義済みの要素を統合し、`Direct edit` `Comments` `Draw` `Tweaks` で仕上げる
- 理由: 最後の20%は人間の審美眼が必要だから

この流れは品質向上だけでなく、限られたトークン予算を守る戦略でもあります。

## 5. 実践: AIにルールを学習させる

`Design Systems` タブで `Create New` を選び、以下のような構造化プロンプトで定義を始めます。

```text
[Visual Identity Definition Prompt]

- Brand Personality: [Professional, trust-driven, bold]
- Target Audience: [Tech-savvy entrepreneurs]
- Design Principles: [Minimalism, high contrast, generous white space]
- Colors & UI Details: [Hex codes, button styles, spacing rules]
```

生成後はレビューし、違和感があれば `Needs work` を押して微調整します。

一度よいシステムができれば、それは以後ずっと再利用できる資産になります。

## 6. まとめ

AIは `制作` に強く、人間は `判断` に強いです。

- AIが制作の80%を担う
- 人間が最後の20%を判断する

この役割分担を守ることで、スピードと品質を両立できます。

さらに、完成したデザインは `Handoff to Claude Code` で実装へつなげられます。見た目だけのモックではなく、機能するプロダクトへ移行しやすくなります。

最初の一歩はシンプルです。`Design Systems` タブを開き、ブランドの性格と色を定義することから始めます。
