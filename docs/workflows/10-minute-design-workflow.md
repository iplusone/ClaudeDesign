# Claude Designで高品質な成果物を10分で作る4つのステップ

Claude Design で短時間に一貫性のある成果物を作るコツは、デザイン前に `色` `レイアウト` `文章` をできるだけ定義しておくことです。

## Step 1. デザインシステムを最初に構築する

ブランドカラー、フォント、ボタン、余白ルールなど、ブランドの設計図を先に作ります。

- 目的: 出力のテイストを毎回ぶらさない
- 定義するもの: カラー、タイポグラフィ、UIスタイル、スペーシング
- 実施場所: Claude Design の `Design Systems`

## Step 2. 反復可能なテンプレートを構築する

ランディングページ、スライド、バナーなど、よく使うレイアウトをテンプレート化します。

- 目的: 毎回ゼロから構成を考えない
- 入力例: 参考デザインのスクリーンショット、既存ページ、レイアウト指示
- ポイント: Step 1 のデザインシステムを接続した状態で作る

## Step 3. Skillで文章を事前定義する

コピーを先に固めておくと、Claude Design 内でのやり直しが減ります。

- 目的: デザインツール上でコピー試行錯誤をしない
- 方法: Claude Code / Claude Desktop の Skill でブランドトーンに合う文章を生成する
- 成果物: セクションごとの文章が入った完成版プロンプト

## Step 4. Claude Designで構築して微調整する

テンプレート、デザインシステム、文章が揃った状態で Claude Design に投入します。

1. `From Template` でテンプレートを選ぶ
2. デザインシステムを接続する
3. 準備したプロンプトを貼り付ける
4. `Direct edit` `Comments` `Draw` `Tweaks` で仕上げる

この流れなら、初回出力の時点で完成形にかなり近い状態まで持っていけます。
