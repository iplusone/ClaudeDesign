# AIを「使う」から「統制する」へ

Claude Design を単なる生成ツールではなく、トークン効率と制作再現性を最大化する戦略的な実行エンジンとして運用するための提案書です。

## 1. 10分の制作に潜む格差

従来、高品質なランディングページ、営業資料、UIの制作には、専門デザイナーへの外注費と長い修正期間が必要でした。

一方で現在は、Claude Design を適切なワークフローで使うことで、短時間でプロ級のレスポンシブデザインを構築できます。

Claude Design は単なるウェブサイトビルダーではなく、以下のような幅広い成果物に対応する生成エンジンです。

- スライド資料
- LinkedInカルーセル
- インフォグラフィック
- セールスプロポーザル
- プロダクトUI

ここで重要なのは、制作速度の差はツールの有無ではなく、`トークンの使い方` と `AIへの指示の精度` で生まれることです。

## 2. テイクアウト1: 雰囲気デザインという罠

次のような抽象的な依頼は、`Vibe Designing` の典型です。

```text
AIエージェンシーのLPを作って
```

このやり方では、Claude に次の判断を一度に委ねることになります。

- 色
- フォント
- レイアウト
- コピー
- 構造

結果として、以下の問題が起きます。

- レイアウトが毎回揺れる
- トークン消費が激しくなる
- ブランド個性が薄くなる
- 意思決定の負荷が上がる

### 分析

トークン効率は単なる節約ではなく、制作の利益率そのものです。準備不足の失敗は、利用制限だけでなく判断品質も削ります。

AIに推測させる範囲を最小化することが、戦略的制作の出発点です。

## 3. テイクアウト2: デザインシステムを先に作る

Claude Design を使いこなすための最優先事項は、構造を作る前にブランドの青写真を固定することです。

### デザインシステムの役割

デザインシステムは、ブランドの `設計図` です。

一度構築しておけば、LPでもスライドでも、常にオンブランドな出力を得やすくなります。

### 基本ステップ

1. `Design Systems` タブから新規作成する
2. ブランド名、ターゲット、雰囲気、カラー、フォントを定義する
3. 生成されたHEXコード、タイポグラフィ、ボタンスタイルを確認する
4. `Needs Work` で微調整する
5. 新規プロジェクトごとに必ず接続する

## 4. テイクアウト3: スケルトンをテンプレート化する

レイアウト試行錯誤は、最も避けるべきトークン浪費です。

LP、ケーススタディ、提案書など、繰り返し使う用途ごとに `スケルトン` をテンプレート化します。

### 分析

重要なのは、`構造` と `スタイル` を分離することです。

参考デザインをスクリーンショットで取り込み、テンプレートを作ることで、AIは次の判断から解放されます。

- 何をどこに置くか
- どの順序で構成するか
- 余白や構成の試行錯誤

その結果、AIはブランド適用とコンテンツ流し込みに集中できます。

## 5. テイクアウト4: コピーをデザインから分離する

強いワークフローでは、Claude Design の中でコピーを推敲しません。

### Skillの活用

Claude Desktop や Claude Code で `Skill` を使い、トーン、過去事例、テンプレート構造を踏まえたコピー生成を先に終わらせます。

### Skillの役割

- ブランドボイスに沿った文章を作る
- 各セクションのコピーを事前生成する
- テンプレート指定とコピーを統合した最終プロンプトを作る

### 本質

Claude Design がワークフローなのではなく、ワークフローが Claude Design を機能させます。

## 6. テイクアウト5: 手動調整とClaude Code連携

適切なシステムを通した第1パスは、すでに80%から90%の完成度に達します。

残りの仕上げには、人間の判断と次の4つのツールを使います。

- `Direct edit`: テキストを直接修正する
- `Comments`: 特定要素への変更指示を出す
- `Draw`: スケッチでレイアウト意図を伝える
- `Tweaks`: カラー、モード、レイアウト差分を切り替える

### Claude Code への移行

完成したデザインは `Handoff to Claude Code` で実装へ渡せます。

Claude Design が見た目を担い、Claude Code が次を実装します。

- データベース
- ユーザー認証
- フォームロジック
- バックエンド機能

## 7. 結論

制作のボトルネックは、すでに `生産` から `判断` へ移りました。

AIは生産の80%を担うパートナーであり、人間は最後の20%のセンス、ブランド理解、審美眼を担うストラテジストです。

これから重要なのは、AIをとりあえず使うことではなく、AIを統制するシステムを持つことです。

- トークン効率を高める
- 一貫性を守る
- 制作時間を圧縮する
- 実装までの距離を縮める

システム化された設計こそが、AI格差時代における競争優位になります。
