# Design System Prompt Examples

Claude Design の `Design Systems` で使うための、実用的なプロンプト例です。

## Short Version

```text
ブランド「[ブランド名]」のデザインシステムを作成してください。

目的：
[例：SaaSのランディングページ、営業資料、SNSクリエイティブを一貫したトーンで作れるようにしたい]

ブランドの印象：
[例：信頼感がある、モダン、ミニマル、少し先進的、親しみやすい]

カラー：
- Primary: [#123456]
- Secondary: [#ABCDEF]
- Accent: [#FF6B35]
- Background: [#FFFFFF]
- Text: [#222222]

タイポグラフィ：
- 見出し：力強くモダンなサンセリフ
- 本文：可読性の高いシンプルなサンセリフ

UIスタイル：
- ボタンは[例：角丸8px、フラット、ホバーで少し明るく]
- カードは[例：薄い境界線、やわらかい影、整理された余白]
- フォームは[例：シンプルで視認性が高く、信頼感がある]

レイアウトと余白：
- 余白は広めに取り、詰め込みすぎない
- グリッドは整然としていて、視線誘導しやすい構成にする

避けたいこと：
- テンプレートっぽい安い印象
- 過剰な装飾
- 配色のばらつき
- 読みにくい細い文字

このブランドらしさが一目で伝わる、再利用しやすいデザインシステムにしてください。
```

## Detailed Version

```text
私のブランド「[ブランド名]」のためのデザインシステムを構築してください。
目的は、ランディングページ、プレゼン資料、バナー、SNSクリエイティブなどを、毎回ぶれずに一貫した品質で作れるようにすることです。

以下の条件で定義してください。

1. ブランドの性格
- 業種：[例：AI SaaS / コンサル / D2C / 教育]
- ターゲット：[例：スタートアップ経営者、マーケ担当者、20代後半〜40代のビジネス層]
- 印象：[例：信頼できる、知的、洗練、未来感、過度に冷たくない]
- 避けたい印象：[例：安っぽい、子どもっぽい、派手すぎる、テンプレ感が強い]

2. カラーシステム
以下を定義してください。
- Primary color: [#0A192F]
- Secondary color: [#1F3A5F]
- Accent color: [#FF6B35]
- Background color: [#F8FAFC]
- Surface color: [#FFFFFF]
- Main text color: [#1A1A1A]
- Sub text color: [#5B6573]
色の役割が明確に分かるようにし、CTAや重要情報が自然に目立つようにしてください。

3. タイポグラフィ
- 見出し：モダンで存在感のあるサンセリフ
- 本文：長文でも読みやすいサンセリフ
- キャプションや補足：小さくしても視認性を保てること
見出し・本文・補足でメリハリを作り、情報階層が自然に伝わるようにしてください。

4. コンポーネントスタイル
以下のスタイルルールを定義してください。
- Primary button
- Secondary button
- Cards
- Input fields
- Badges / labels
- Section headings
ボタンは[例：角丸10px、十分な余白、ホバーで少し明るく、クリックしたくなる明快さ]。
カードは[例：白ベース、薄い境界線、弱めのシャドウ、整った余白]。
全体として、プロダクト感と信頼感のあるUIにしてください。

5. スペーシングとレイアウト
- 余白は広めで、呼吸感のあるデザイン
- 情報を詰め込みすぎず、重要な要素が埋もれないこと
- セクション間隔、カード内余白、ボタン周辺の余白に一貫したルールを持たせること
- グリッドは整然としていて、LPにも資料にも応用しやすいこと

6. ビジュアルトーン
- 写真やイラストを使う場合は、[例：高品質・自然光・クリーン・都会的]
- アイコンは[例：シンプル、線がきれい、ミニマル]
- 装飾は最小限にし、洗練を優先すること

7. ブランドらしさ
ランダムなAIテンプレートではなく、「これは[ブランド名]らしい」と感じる統一感を重視してください。
特に、色・余白・タイポグラフィ・CTAの見せ方にブランドの個性を反映してください。

8. 出力の方針
再利用しやすいように、明確なスタイルルールとして整理してください。
ランディングページ、営業資料、SNSクリエイティブに展開しても破綻しないシステムにしてください。
```

## One-Line Refinements

- AI / SaaS向け: `B2B SaaSらしい信頼感と先進性を両立し、スタートアップらしいスピード感も感じさせてください。`
- 高級ブランド向け: `高級感、静けさ、余白の美しさを重視し、安易な派手さは避けてください。`
- 教育サービス向け: `親しみやすさと安心感を持たせつつ、幼くなりすぎないバランスにしてください。`
