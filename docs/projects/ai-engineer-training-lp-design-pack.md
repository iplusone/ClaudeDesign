# AI活用エンジニア育成サービス LP デザインパック

これからのエンジニア志望者向けに、AIを活用した育成カリキュラムへの問い合わせ獲得を目的とした LP を作るための実行用パックです。

参考トーンは [OCL AI](https://ocl-ai.jp/) のような `信頼感` `わかりやすさ` `機能の整理された見せ方` を参考にしつつ、対象読者を `これからのエンジニア志望者` 向けに調整しています。

## 1. プロジェクト前提

- 制作物: ランディングページ
- 目的: 育成カリキュラム / 教育プログラムへの問い合わせ獲得
- ターゲット: これからのエンジニア志望者
- トーン: 信頼感があり、先進性も感じる
- 構成: Hero / 課題 / サービス内容 / カリキュラム内容 / FAQ / CTA

## 2. Design System 用プロンプト

Claude Design の `Design Systems` で新規作成するときは、以下をそのままベースに使えます。

```text
私のブランド「[サービス名]」のためのデザインシステムを構築してください。
目的は、AIを活用したエンジニア育成サービスのランディングページ、説明資料、SNSクリエイティブを、毎回一貫した品質で作れるようにすることです。

以下の条件で定義してください。

1. ブランドの性格
- 業種: 教育 / キャリア支援 / AI × エンジニア育成
- ターゲット: これからエンジニアを目指す学生、第二新卒、キャリアチェンジ希望者、20代〜30代前半
- 印象: 信頼できる、知的、先進的、親しみやすい、未来志向
- 避けたい印象: 情報商材っぽい、過度に煽る、子どもっぽい、安っぽい、派手すぎる

2. カラーシステム
- Primary color: #0A192F
- Secondary color: #163A6B
- Accent color: #3B82F6
- Warm accent color: #F59E0B
- Background color: #F6F8FC
- Surface color: #FFFFFF
- Main text color: #111827
- Sub text color: #5B6573
CTAや重要情報が自然に目立ち、学習サービスとして安心感のある配色にしてください。

3. タイポグラフィ
- 見出し: モダンで力強いサンセリフ
- 本文: 長文でも読みやすいサンセリフ
- 補足: 小さくても可読性を保てること
情報階層が自然に伝わるようにしてください。

4. コンポーネントスタイル
- Primary button
- Secondary button
- Cards
- FAQ accordion
- Input fields
- Section headings
ボタンは角丸10px前後、十分な余白、クリックしやすい明快さを持たせてください。
カードは白ベース、薄い境界線、弱めのシャドウ、整理された余白で、学習内容や特長を見やすく整理できるようにしてください。

5. スペーシングとレイアウト
- 余白は広めで、安心感のある呼吸感を作る
- 情報は整理され、初学者でも理解しやすいこと
- セクション間、カード内、CTA周辺の余白に一貫性を持たせる
- LPに最適化された整然としたグリッドを使う

6. ビジュアルトーン
- 写真やイラストは、未来感、学習、成長、挑戦を感じさせるもの
- アイコンはシンプルで整理された線画またはミニマルな面スタイル
- 装飾は最小限にし、信頼性と先進性を優先する

7. ブランドらしさ
ランダムなAIテンプレートではなく、「AI時代のエンジニア育成ブランド」らしい統一感を重視してください。
特に、見出しの力強さ、CTAの安心感、余白の使い方、学習ロードマップの見せ方に個性を反映してください。

8. 出力の方針
再利用しやすいように、明確なスタイルルールとして整理してください。
ランディングページや説明資料に展開しても破綻しないシステムにしてください。
```

## 3. Skill 用ブリーフ

Claude Code / Claude Desktop の Skill に渡すときは、以下の埋めた版を使えます。

```text
以下のブリーフをもとに、Claude Design用の完成プロンプトを作成してください。

【制作概要】
- 制作物: ランディングページ
- 目的: AIを活用したエンジニア育成カリキュラムへの問い合わせ獲得
- 公開場所: サービス公式サイト
- 想定公開時期: できるだけ早く

【ターゲット】
- 想定読者: これからエンジニアを目指したい人
- 業種 / 役職 / 属性: 学生、第二新卒、未経験からIT業界を目指す社会人
- 現在の課題: 学習の進め方が分からない、何から始めるべきか不安、独学が続かない、AI時代に通用するスキルが知りたい
- 読者に取ってほしい行動: 問い合わせを行う

【ブランド情報】
- ブランド名: [サービス名]
- ブランドトーン: 信頼感、先進性、親しみやすさ、未来志向
- 避けたい表現: 煽りすぎる表現、根拠のない断定、情報商材っぽさ
- 参考にしたい過去コピー: まだ未定

【訴求内容】
- いちばん伝えたい価値: AI時代に合った学び方で、未経験からでも実践力のあるエンジニアを目指せる
- 提供サービス / 商品: AI活用型エンジニア育成プログラム
- 強み / 差別化ポイント: AIを使った学習支援、段階的なカリキュラム、実践課題、つまずきにくい導線、現場を意識した育成
- 実績 / 数字 / 導入事例: 未定の場合は数字を無理に作らず、プレースホルダーとして扱う
- FAQに入れたい内容: 未経験でも大丈夫か、AIを使った学習とは何か、受講期間、必要なPCスキル、料金や相談方法

【構成】
- 使いたいテンプレート候補: 教育サービスLP、SaaSライクな構成、信頼感のあるコーポレートLP
- 必須セクション: Hero、課題、サービス内容、カリキュラム内容、FAQ、CTA
- 不要なセクション: 過度な比較煽り、派手すぎる実績演出
- CTA: まずは無料相談 / カリキュラムについて問い合わせる
- CTAの遷移先: 問い合わせフォーム

【デザイン連携前提】
- 使用するデザインシステム名: [サービス名] Design System
- 使用するテンプレート名: Education LP Template
- 想定する雰囲気: 信頼感があり、先進的で、未経験者にもやさしい
- 参考URL / 参考デザイン: https://ocl-ai.jp/

【出力してほしいもの】
1. 推奨テンプレート
2. 推奨セクション構成
3. Hero / Problem / Service / Curriculum / FAQ / CTA の各セクションコピー
4. 必要なら Hero見出しとCTAのバリエーション
5. Claude Designにそのまま貼れる統合プロンプト
```

## 4. Claude Design 用 完成プロンプト

以下は、`From Template` と `Design System` を接続したあとに Claude Design へ貼るための完成プロンプトです。

```text
AIを活用したエンジニア育成サービス「[サービス名]」のランディングページを作成してください。

必ず、接続済みのデザインシステムに従ってください。
レイアウトは、教育サービスまたはSaaSライクな信頼感のあるLP構成を使用してください。
対象は、これからエンジニアを目指す学生、第二新卒、未経験からIT業界へ挑戦したい社会人です。
トーンは、信頼感、先進性、親しみやすさ、未来志向です。
過度に煽らず、安心して一歩踏み出せる印象にしてください。

使用するセクションは以下です。

1. Hero
- 見出し: AI時代の学び方で、未経験からエンジニアへ。
- サブコピー: これからのエンジニア志望者に向けた、AI活用型の実践育成プログラム。学ぶ順番、つまずきやすいポイント、実践へのつなげ方まで、迷わず進めるカリキュラムを提供します。
- CTA: まずは無料相談する
- Secondary CTA: カリキュラムの詳細を見る

2. Problem
- セクション見出し: こんな不安を感じていませんか？
- 課題1: 何から学べばいいのか分からない
- 課題1説明: 情報が多すぎて、最初の一歩で止まってしまう。
- 課題2: 独学が続かず、理解があいまいなまま進んでしまう
- 課題2説明: 一人ではつまずきに気づきにくく、学習が止まりやすい。
- 課題3: AI時代に必要なスキルが分からない
- 課題3説明: ただコードを書く力だけでなく、AIを活用して成果を出す力が求められている。

3. Service
- セクション見出し: [サービス名] が提供すること
- サービス説明: [サービス名] は、未経験からでも実践的に学べるAI活用型エンジニア育成プログラムです。基礎学習だけで終わらず、考える力、作る力、AIを使いこなす力まで育てます。
- 特長1: AIを活用した学習サポート
- 特長1説明: 調べ方、理解の整理、反復学習を支える仕組みで、学習効率を高めます。
- 特長2: 段階的なステップ設計
- 特長2説明: 初学者でも迷いにくい順序で、基礎から実践へ進めます。
- 特長3: 実践を意識したアウトプット
- 特長3説明: 手を動かしながら学び、ポートフォリオや実務感覚につながる経験を積めます。

4. Curriculum
- セクション見出し: カリキュラム内容
- 導入フェーズ: 学習の土台づくり
- 導入フェーズ説明: IT基礎、開発の全体像、学習の進め方を理解します。
- 基礎フェーズ: 開発スキルの基礎習得
- 基礎フェーズ説明: フロントエンド、バックエンド、データベースなどの基礎を段階的に学びます。
- 応用フェーズ: AI活用と実践課題
- 応用フェーズ説明: AIを使った実装補助、要件整理、改善の進め方を学びます。
- 実践フェーズ: 作品制作とアウトプット
- 実践フェーズ説明: 自分の成果物として形にし、実務に近い経験へつなげます。

5. FAQ
- 質問1: 未経験でも受講できますか？
- 回答1: はい。初学者がつまずきやすいポイントを前提に設計しているため、基礎から段階的に学べます。
- 質問2: AIを活用した学習とは何ですか？
- 回答2: AIを単なる便利ツールではなく、理解整理、反復、実装支援に活かしながら、これからの開発現場で必要な使い方を学ぶことです。
- 質問3: どれくらいの期間を想定していますか？
- 回答3: 学習ペースや目的によって異なります。個別相談の中で最適な進め方をご案内します。
- 質問4: どんな人に向いていますか？
- 回答4: これからエンジニアを目指したい方、独学に限界を感じている方、AI時代に合った学び方をしたい方に向いています。
- 質問5: まず何をすればいいですか？
- 回答5: まずは無料相談からご参加ください。現在地と目標に合わせて、学び方の方向性を一緒に整理します。

6. CTA
- セクション見出し: 学び方が変われば、未来の選択肢も変わる。
- 説明: 未経験からでも、正しい順序と正しい支援があれば、エンジニアへの一歩は現実になります。まずは無料相談で、あなたに合った学習の進め方を確認してください。
- Primary CTA: 無料相談を申し込む
- Secondary CTA: 問い合わせる

デザイン上の注意:
- 初学者にとってわかりやすい情報階層にする
- 信頼感のある余白と整然としたレイアウトを維持する
- カードやセクションで情報を整理し、読了しやすくする
- 先進性は出しつつ、過度に難しそうな印象は避ける
- 参考サイトのように、クリーンで整理された情報提示を意識する
```

## 5. 補足

- 数字実績や受講者の声がある場合は、`Service` または `Curriculum` の後に `Proof` セクションを追加すると強くなります。
- 料金を明示したい場合は、CTA前に `Pricing` セクションを追加すると問い合わせの質を調整しやすくなります。
- ブランド名、実績、相談導線URLが決まったら最終版に差し替えると、そのまま本番に近い精度で使えます。
